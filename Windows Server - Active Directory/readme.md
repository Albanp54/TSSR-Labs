# Infrastructure Active Directory

## Objectifs

- Mettre en place un domaine et gérer les taches courantes
d'administration au sein d'un domaine
- Gérer l'accès aux ressources 

## Environnement
- Windows Server 2022
- Windows 10
- VirtualBox

## Active Directory
- Création du domaine et mise en place du DC
- Création des utilisateurs et organisation logique via UO
- DNS
- DHCP

## Stratégies de groupe
- Restriction à l'accès au panneau de configuration
- Mappage d'un lecteur réseau

## Gestion des fichiers
- Création d'un partage SMB
- Création de groupes pour la gestion des autorisations
- Gestion des permissions NTFS sur les ressources du partage

## Tests
- Application des GPO
- Accès autorisés/refusés aux partages
